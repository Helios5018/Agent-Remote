# CMUX Agent Remote

运行在 Mac 上的多 Agent Web 控制中心，通过浏览器和手机查看、控制 cmux 中的 Claude、Codex、Grok 和 Pi。核心是及时知道谁在工作、谁在等你，并能立即接手。

```text
Agent → cmux Surface → 本地 Bridge → Web / 手机
```

## 快速开始

需要 Bun 和 cmux。长驻服务放在 tmux 中运行：

```bash
bun install
bun run build
tmux new-session -d -s agent-remote-web 'bun run start'
```

默认访问 `http://127.0.0.1:4318`，首次输入服务日志中的 Access PIN。

```bash
# 查看日志（包含首次登录 PIN）
tmux capture-pane -pt agent-remote-web -S -80
# 停止服务
tmux kill-session -t agent-remote-web
# 可选：安装 Agent Hook，获取更精确的状态
bun run install-hooks
```

启动参数：`--lan` 开放局域网、`--demo` 使用假数据、`--rotate-pin` 轮换 PIN、`--unlock` 清除登录锁定。持久化数据默认在 `~/.cmux-agent-remote/`。

已有服务优先复用端口和 tmux session。公网更新见 [公网暴露指南](docs/公网暴露指南.md)，不要为了更新代码重建隧道。

## 外部 Agent 如何接入

能发送 HTTP 请求的 Agent 可以直接使用这个服务，无需安装 Skill、MCP 或 SDK。先确认服务已运行包含 HTTP 接入功能的版本；已有公网服务需按 [公网暴露指南](docs/公网暴露指南.md) 原地更新。

给 Agent 提供三样信息：**服务根地址、Access PIN、本次任务和授权范围**。同一台 Mac 上可以使用 `http://127.0.0.1:4318`；其他机器上的 Agent 使用它能访问的局域网或公网地址，不能使用你这台 Mac 的 localhost。根地址不包含网页的 `#/` 或 `#/s/...`。

可以把下面这段发给 Agent，替换占位内容；PIN 通过私密会话或凭证工具单独提供，不写进项目文件：

```text
请通过 Agent Remote 操作我的 Mac。
服务根地址：<baseUrl>
先读取使用指南：<baseUrl>/agent-guide.md
Access PIN：通过本次私密会话或指定凭证来源获取
任务及授权范围：<具体项目目录、目标会话，以及允许执行的操作>

按指南登录并复用 Cookie，读取实例信息和会话结构，再读取目标会话的 context。
核对实例、surface UUID、程序和目录后执行任务，通过输出和产物验证结果。
如果输入或创建请求超时，先观察现场，不自动重发正文或重复创建。
```

指南公开可读，业务接口需要登录。最短调用顺序：

1. `POST /api/auth/login`，正文 `{ "token": "<Access PIN>" }`，保存并复用返回的 Session Cookie。
2. `GET /api/info` 核验实例身份，`GET /api/tree` 找到目标 surface UUID。
3. `GET /api/surfaces/<UUID>/context` 查看程序、状态、工作目录、Git 摘要及最近输出。
4. 核对目标后，`POST /api/surfaces/<UUID>/input` 发送 `{ "text": "任务正文", "submit": true }`，再观察结果。普通 Shell 会把文本当命令，务必确认前台程序。

需要专用 Shell 时，调用 `POST /api/workspaces`，正文 `{ "cwd": "/已存在的项目绝对目录", "launch": null }`，再使用返回的 surfaceId。创建成功不代表目录初始化或程序已就绪，先读取 context 核对。

完整 Python 示例、上传下载、文件和 Git 接口、地址/PIN 变化后的恢复方式见 [Agent HTTP 接入指南](docs/agent-guide.md)。运行时同一份指南位于 `<baseUrl>/agent-guide.md`；URL 变化后换用新地址登录，并通过 `/api/info` 的 instanceId 核验是否仍为同一实例。

## 页面

| 地址 | 用途 |
|---|---|
| `#/` | 按 Workspace → Pane → Surface 展开的首页 |
| `#/w/:id` | 单 workspace 深链 |
| `#/s/:id` | 终端画面、历史、输入和控制键 |

支持搜索、折叠、只看 Agent、新建/关闭 surface、改名、缩放和沉浸显示。Pi 会话提供 Ctrl+P 切换模型。详见 [使用说明](docs/usage.md)。

## 按需文件浏览器

Agent 详情页默认不显示文件页签。在右上角「⋯」选择「打开文件系统」后，在顶栏出现「会话 / 文件」切换并进入文件页。文件页「⋯」或详情页「⋯」都可以关闭模块，关闭不会删除文件。每个 Agent 在当前浏览器中独立保存是否打开、目录标签、选中项、滚动位置和剪贴板。切换详情页不会串用文件状态。主动关闭文件系统会清空该 Agent 的全部目录标签和剪贴板；再次打开重新从该 Agent 的工作目录进入（获取失败回到主目录），不会恢复已关闭的状态。

- 默认仅显示一行目录导航；路径以 `~/…` 面包屑常驻显示，长路径可横向滑动，默认露出末尾，点击上级目录返回；点击搜索展开搜索框，新建、刷新和隐藏项等收进「⋯」，菜单以柔和颜色区分创建、整理、浏览和关闭。默认显示隐藏文件，可从菜单切换。多个目录标签时才展示标签栏，手机在文件列表左右滑动切换。
- 长按或菜单「选择文件」进入多选，选中时才显示复选框和操作栏。窄屏预览覆盖列表；页面宽度达到 1200px 时左侧 Agent、右侧文件系统并排显示，不显示会话 / 文件切换；文件区宽度达到 900px 时展开上级目录 / 当前目录 / 当前项内容三列（文件夹显示下级内容，文件显示预览）；鼠标悬停或上下键移动当前项，右列点击或右方向键进入目录，左方向键返回上级，否则为一列；切回会话默认回到最新输出底部。
- 当前目录筛选、递归文件名搜索、文本内容搜索；每页 100 项，点击底部加载更多。
- 文本、代码、Markdown 源文、图片及音视频预览；复制地址、新建文件 / 文件夹、重命名、多选复制 / 剪切粘贴、删除。删除先确认清单，再输入“删除”并点击“永久删除”，不会进入废纸篓；确认期间项目变化需重新确认。冲突拒绝覆盖，请改名后重试。
- 初次打开尝试使用当前 Agent 的工作目录；获取失败时回到主目录。文件菜单可随时转到当前 Agent 工作目录。

文件浏览器可访问整台 Mac 的文件系统，不限制在项目或 Agent 工作目录内；实际读写权限由运行服务的 macOS 用户决定。所有文件接口仍需登录。菜单提供主目录 `~` 快捷入口。文件模块不依赖 cmux，会话只是入口。

会话输入支持正文内文件引用：输入框 `＋` 提供「照片与视频」「上传文件」「选择 Mac 文件」。相册和手机系统文件选择器里的文件先上传到运行服务的 Mac；Mac 文件选择器复用上述文件浏览器，已有文件直接引用，不复制上传。也可以从文件面板点击「插入当前会话」、多选插入，或把文件条目拖进输入框。电脑支持拖入本机文件和粘贴截图。

引用显示在正文光标位置，沿用文件浏览器的类型图标；点击可查看完整路径、预览、复制路径、重试失败上传或移除引用。发送和复制选区时展开为带引号的绝对路径，保留与文字的前后顺序；移除引用不会删除磁盘文件。上传未完成或失败时阻止发送，上传进度和草稿在切换会话时保留；刷新网页或登出会清除内存草稿。上传成功只代表文件已保存，Agent 是否能理解图片、视频或文档，取决于其读取工具和模型能力。

单文件上传上限 512 MB，最多同时传输两个文件，服务端流式落盘。默认保存到 `~/.cmux-agent-remote/uploads/YYYY-MM-DD/<唯一ID>/<原文件名>`（日期按 UTC；设置 `CAR_DATA_DIR` 时跟随数据目录），同级 `<唯一ID>.json` 记录所属 surface、文件名、大小和上传时间，不记录提示词。上传中断会清理本次暂存目录；已经成功保存的附件不自动删除，关闭会话也保留。可通过文件浏览器自行管理 `uploads`，删除后历史引用将失效。

文本预览上限 128 KB；内容搜索检查 128 KB 内的文本，跳过 `.git` / `node_modules`，最多扫描 20000 项或 5 秒，可取消。图片预览和下载上限 20 MB；音视频播放通过分段流式读取，不受此上限限制，支持原生播放控件和进度跳转，关闭预览会停止播放。支持 MP4 / MOV / WebM、MP3 / M4A / WAV / Ogg / FLAC 等容器，实际能否播放取决于浏览器对文件编码的支持，不进行服务端转码。单次复制最多 100 个选中项、递归 10000 项或 512 MB，软链接和特殊文件不参与复制。复制失败会提示已完成数量，目标目录可能保留部分内容；刷新后检查。剪切在目标目录粘贴成功后才移除原项目，同盘直接移动，跨盘先暂存复制再移除源文件（跨盘沿用复制大小限制）。部分失败时保留未完成的剪切项。当前不提供正文编辑。

三列鼠标交互：中列点击只切换当前项；右列点击前进一级并选中该项，文件自动预览；左列点击返回上一级；左列和右列的空白区域也可点击，将该列目录切换到中列。三列共用紧凑列表行，并以不同形状和柔和颜色的图标区分文件夹、代码、配置、图片、音视频、压缩包、PDF、文档等类型。窄屏保留单列点击进入。电脑上的快捷键在文件区获得焦点时生效（单列也支持），不接管 Agent、输入框、播放器或确认弹窗。

快捷键采用 [yazi 默认键位](https://yazi-rs.github.io/docs/quick-start/#keybindings)：方向键 / hjkl 导航；Space 切换多选；v / V 连续选择 / 取消；Ctrl+A 全选已加载项，Ctrl+R 反选，Esc 取消；y 复制、x 剪切、p 粘贴、Y / X 清空剪贴板；d 移到 macOS 废纸篓（一次确认）、D 永久删除（两次确认）；r 重命名、. 显示隐藏项、f 筛选。菜单“快捷键说明”或 F1 / ~ 可查看。本版不提供强制覆盖粘贴。

### Git 状态

进入 Git 仓库后，文件区自动显示仓库、当前分支、变更数量和上游领先 / 落后提交数；文件与目录使用 Yazi git.yazi 默认状态符号及颜色，字体已内嵌，手机无需安装 Nerd Font。目录按 Yazi 的状态优先级汇总，忽略文件不会把父目录标为忽略。

点击摘要在原文件区展开「概览 / 变更 / 分支 / 提交」。变更按冲突、未暂存、已暂存、未跟踪分组，可读 Diff 与文件内容。分支分为本地、远程，点击只浏览该分支历史，不切换工作区。提交支持分页、完整说明、文件清单和 Diff；合并提交与第一父提交比较。

进入时先显示本地信息，后台自动 fetch 默认 remote（优先分支配置，其次 origin 或唯一 remote），同仓库 5 分钟冷却并合并并发请求。概览可手动刷新。fetch 不等待交互认证，30 秒超时；失败保留本地远程跟踪信息并显示原因及本应用最近成功时间。只更新远程跟踪分支，不 pull、checkout、暂存或提交；不自动清理远程已删除分支。Git 读取接口位于登录后的 `/api/git`，目录路径独立于 surface。

文件区打开时每 10 秒刷新本地状态，页面隐藏时暂停，回到窗口立即刷新。Git 命令限制运行时间与输出体积，Diff / 文本预览有约 256 KB 展示上限，超限明确提示；二进制文件只展示状态。
