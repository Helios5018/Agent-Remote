## 2. V0 完成标准闭环（需求文档 §24 / §32）

真机实测（cmux workspace「CAR E2E Test」中运行一个进程名为 `codex` 的测试 Agent）：

```text
浏览器输入：很好，继续检查一下边界 case，然后提交 commit。
   ↓  POST /api/surfaces/DC4822B4-…/input  (control mode)
cmux surface:62 收到并执行
   ↓
终端输出变化
   ↓  WebSocket surface.snapshot rev=3
浏览器立即看到 [agent] received: 很好，继续检查一下边界 case，然后提交 commit。
```

状态流转（真机）：

```text
IDLE → （Web 发送 prompt）→ WORKING · Thinking
     → （输出静止 15s）    → RESPONDED_UNREAD（活动文案已清空）
     → （打开会话）        → IDLE
```

首页在同一时刻出现：`CAR E2E Test / Codex / ◇ Responded`。

## 3. Hook 链路真机验证

用真实的 `scripts/cmux-agent-web-hook` 脚本，对一个真实 Grok surface 上报：

```bash
echo '{"session_id":"live-test","tool_name":"bash",
       "message":"Grok needs your permission to use bash"}' |
  CMUX_SURFACE_ID=5877E341-… ./scripts/cmux-agent-web-hook grok Notification
# exit 0
```

结果：该 Agent 立刻变成 `NEEDS_APPROVAL`，活动文案为原始通知内容，并排到首页 NEEDS YOU 首位；
`hookConnected` 置为 true（之后不再依赖输出推断）。随后 `Stop` → `RESPONDED_UNREAD`，
`POST /api/agents/:id/read` → `IDLE`。

失效场景（全部返回 200 / exit 0，不影响 Agent）：
token 错误、未知 agent、非法 JSON、未知事件名、关联不到 surface、服务完全没启动、没有配置文件。

## 4. WebSocket 断线恢复真机验证

| 时刻 | 动作 | 页面状态 |
|------|------|----------|
| T0 | 正常连接 | `conn-open`，无横幅 |
| T1 | `tmux kill-session` 停掉服务 6s | `conn-closed`，横幅「连接中断，正在自动重连…（已退化为轮询）」 |
| T2 | 重启服务 | 约 5s 内自动 `conn-open`，横幅消失，10 个 Agent 正常显示，**无需重新输入 Token** |

（Session 持久化在 SQLite 中，重启后不用重新输入 PIN。）

## 5. 安全项验证

| 项 | 验证 |
|----|------|
| 未登录 | `/api/agents`、`/api/tree`、`/api/surfaces/:id/output`、`/api/audit` 全部 401 |
| 登录后写入 | PIN 登录后即可 `POST /input` / `/key`，不再分只读 / 控制模式 |
| Ctrl+C | 未确认 428 `CONFIRM_REQUIRED`；带 `confirm:true` 才真正发送 |
| 非法按键 | `ctrl+d` / `ctrl+z` / `f5` / 空串 → 400（`ctrl+d` 实测会关掉 surface，故不进白名单） |
| 命令注入 | prompt 含 `$(rm -rf /)` 与 `--help` 时按字面文本传递（参数数组 + `--`） |
| 审计 | 记录 `surface.input len=19 submit=true`，**不含 prompt 原文** |
| 目录穿越 | 静态文件服务对 `..` 路径返回 403 |
| PIN 爆破 | 连错 4 次提示剩余次数，第 5 次 429 + `Retry-After: 60`，锁定期间正确 PIN 也拒绝；服务端打印 `[security]` 告警 |
| Hook 密钥隔离 | 用 PIN 打 `/api/hooks` 被忽略；远程 IP / 带 XFF 的请求一律 `ignored: remote origin` |
| 代理头伪造 | 默认不信任 `X-Forwarded-For`，换头刷不掉限流 |

## 7. 已知限制（第一版不做，见需求文档 §3.2）

- 不是完整 Terminal Emulator：只还原 cmux 已经渲染好的画面（颜色 / 格子宽度 / 光标），
  不接管键盘、不能改终端列数（`terminal.viewport` 对第三方客户端只读），窄屏靠缩放或换行适配。
- 没有安装 Hook 时，状态靠输出变化推断：TUI 动画多的 Agent 可能出现短暂 `WORKING` 误判；
  装上 Hook 后完全以 Hook 为准。
- 单用户单 PIN，无 2FA、无设备绑定、无多用户协作、无云端 Relay（V2 范围）。
- 长期挂公网建议 6 位以上 PIN，或在前面套 Tailscale / Cloudflare Access，
  详见 [公网暴露指南.md](../公网暴露指南.md)。
- tmux 长任务、Project 聚合属于 V1 范围，本版未实现。
- Session 持久化在本机 SQLite；`--rotate-pin` 可一键作废所有设备。
